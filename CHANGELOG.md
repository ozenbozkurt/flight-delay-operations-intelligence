# Changelog

All notable maintained changes to this project are documented here.

The project follows semantic versioning for maintained releases.

## Unreleased

### Added

- Support for documented official BTS uppercase CSV column aliases, including required fields and optional cancellation/delay-reason fields (#6).
- Turkish quickstart for local CSV analysis (#8).
- Project roadmap for the v0.2.0 milestone (#9).
- Feature-request and strengthened pull-request contribution templates (#10).

### Changed

- Contributor guidance now makes compatibility, regression coverage, documentation, and data-licensing checks explicit.

### Planned for v0.2.0

- Memory-bounded CSV analysis for large datasets, subject to compatibility review and regression testing (#7).

## v0.1.0 — 2026-09-14

First maintained release.

### Added

- Reusable `flight-delay` command-line interface.
- Reusable Python `analyze` API.
- Synthetic demo dataset and regression tests.
- Optional chart generation.
- Windows/Linux GitHub Actions test matrix.
- Packaging metadata and MIT licensing for project code, synthetic examples, and documentation.
- Explicit data-source and redistribution boundary for historical repository datasets.
